Design System Analysis of Pinterest

A photography-first discovery system. In dark mode the warm-cream chrome inverts to a warm-tinted near-black canvas while Pinterest Red stays untouched as the brand anchor. Pin masonry, 16px-radius cards, and the same sticky red Sign-up CTA — only the surface ladder changes.

Touch Targets

  • WCAG AA: button-primary at 40px height with 14px padding (~40×80px).
  • Search bar: 48px height. Text input: 44px.
  • Filter chip: ~36–40px extends to 44px tappable via padding.
  • Icon-circular button: 40×40 with 48×48 hit-target padding.

Collapsing Strategy

  • Primary nav: desktop horizontal → tablet hamburger drawer.
  • Search bar: 480px → 320px → magnifier icon overlay.
  • Pin masonry: 5–6 → 4 → 3 → 2 → 1 columns.
  • Modal: centered ~480px → full-width sheet on mobile.
  • Section padding: 64px → 48px → 32px.
  • Hero headline: 70px → 56px → 44px → 36px.
  • Footer: 4-up → 2-up → accordion.
