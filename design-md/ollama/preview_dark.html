Design System Analysis of Ollama

An almost defiantly minimal documentation-first system that treats the home page like a Markdown README. In dark mode the canvas inverts to deep neutral while the chrome stays single-color: a white pill CTA on a near-black canvas, translucent-white hairlines, and the same install-snippet pill rendered on a slightly elevated dark surface.

Stacked rows with 16px vertical padding and translucent-white 1px dividers. Always expanded — no accordion.

Which models are available?

See the full list of cloud-enabled models in the documentation.

Do models support tool calling?

Models support tool calling and run agent workflows before they go live.

What quantization or data format do cloud models use?

Native weights, as released by the model provider. On modern hardware, models may use accelerated data formats.

Speed depends on model size, architecture, and hardware optimization.

Touch Targets

  • WCAG AA: button-primary and button-secondary at 36px height with 20px padding.
  • Text input: 40px height with 16px padding.
  • Search pill: 36px height with 16px padding.
  • Footer links: 12px caption with line-height + vertical padding (~32–36px tap row).

Collapsing Strategy

  • Primary nav: desktop horizontal → tablet-narrow hamburger drawer at 768px.
  • Pricing grid: 3-up → 2+1 → 1-up stacked.
  • Hero headline: 36px → ~28px at mobile.
  • Section spacing: 88px → 64px → 48px.
  • Install snippet: wraps to 2 lines on narrow screens.
