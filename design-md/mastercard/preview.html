Design System Analysis of Mastercard

A complete, token-level catalog generated from DESIGN.md. Every color, type scale, button, card, and radius below is rendered using the same values documented for downstream agents.

Section 01

Color Palette

Six role groups built on a warm putty-cream canvas. Ink is warm near-black. Signal Orange is reserved for consent/legal; Light Signal Orange traces decorative orbits. The Mastercard logo red and yellow are brand-mark colors only.

Primary

Mastercard Red
#EB001B
Left circle of the brand mark — logo only, never a UI color.
Mastercard Yellow
#F79E1B
Right circle of the brand mark — logo only, never a UI color.
Ink Black
#141413
Primary CTAs, headline text, footer surface. Slightly warm near-black.

Secondary & Accent

Signal Orange
#CF4500
Consent/legal actions and eyebrow accent dots. Reserved color.
Light Signal Orange
#F37338
Carousel active indicators and decorative orbital arcs.
Clay Brown
#9A3A0A
Deep rust for secondary link-style buttons (e.g., details).

Surface & Background

Default body background. Warm putty tone — never pure white.

#FCFBFA

White

Neutrals & Text

Semantic & Accent

Link Blue

Everything set in MarkForMC (Sofia Sans as open-source substitute). Display weight 500 with −2% tracking, body weight 450 for the signature airy tone, and a single uppercase eyebrow at +4% tracking.
